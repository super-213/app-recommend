## 一、现状总结

**整体风格**：米白底（`#f6f7f3`）+ 白色卡片 + 深绿主色 + 细边框 + 大圆角，是"安静工具箱"的调性，一致性良好。

**做得好的地方**

- 深绿色只用在"全部"选中态和"推荐"徽标上，克制且有识别度。
- 软件图标让卡片辨识度明显提升。
- 搜索框 + `⌘K` 提示位置自然，符合效率工具类站点的预期。
- 卡片结构清晰：图标 → 名称 → 简介 → 标签。
- 灰色偏暖偏绿，与米白底协调。

## 三、具体问题与修改建议

### 1. 图标与标题垂直对齐不一致（P0）

**现象**：第一行 CleanupBuddy、Folo 的标题 y≈392，Itsycal 的标题 y≈403；第二行也有 1~2px 差异。原因是各图标实际尺寸不同，撑开了容器高度。

**建议**：给图标容器固定宽高，图标内部用 `object-fit: contain` 居中。

```css
.card-icon {
  width: 52px;
  height: 52px;
  flex: none;
  display: grid;
  place-items: center;
  border-radius: 14px;
  overflow: hidden;
}
.card-icon img {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

### 2. 图标风格与容器处理统一（P1）

**现象**：有真人头像风、橙色方块、线稿笑脸；有的带浅灰描边框，有的没有，圆角也不同。

**建议**：统一圆角和一圈极淡描边，把差异收敛到同一视觉框架内。

```css
.card-icon {
  border-radius: 14px;
  box-shadow: inset 0 0 0 1px rgba(0, 0, 0, 0.06);
  background: #fff;
}
```

### 3. 顶部标签分组与统一（P0）

**现象**

- 11 个标签平铺：分类（存储管理、开发工具…）、`agent`、平台（Linux、macOS、Windows）混在一起。
- `agent` 为小写英文，与其他标签风格不一致。

**建议**

- 拆成两组：**分类**与**平台**，用细分隔线或两行展示。
- 统一命名风格：`agent` → `Agent` 或"智能体"。
- 平台标签用更小、更淡的样式，让分类作为主筛选。

```
TAGS       [全部] [存储管理] [开发工具] [实用工具] [网络工具] [系统工具] [效率工具] [Agent]
PLATFORM   [macOS] [Windows] [Linux]
```

### 4. 卡片内标签层级（P0）

**现象**：推荐 / 平台 / 分类三类标签字号、灰度几乎一致，仅"推荐"有色块；"自己制作"这一最具个人特色的信息没有被突出。

**建议**

| 标签类型 | 样式建议 |
|---|---|
| 状态：推荐 | 浅绿底 + 深绿字（保持现状） |
| 状态：自己制作 | **使用不同强调色**，如赭色/琥珀色浅底 + 深色字 |
| 平台 | 更淡、更小，仅描边或浅灰底 |
| 分类 | 保持现有灰底样式 |

可选增强：给"自己制作"的卡片加左侧 2~3px 色条，或在列表顶部增加"我做的"分组。

```css
.tag--mine {
  background: #f6ead7;
  color: #8a5a14;
}
.tag--platform {
  background: transparent;
  box-shadow: inset 0 0 0 1px rgba(0, 0, 0, 0.08);
  color: #7a8078;
  font-size: 11px;
}
```

### 5. 右上角箭头与 hover 反馈（P1）

**现象**：`↗` 颜色过淡，不 hover 时几乎看不见；卡片缺少可点击的明确反馈。

**建议**

- 默认箭头加深一档。
- hover 时卡片轻微上浮、边框变深，箭头变主色并略微位移。
- 增加 `:focus-visible` 样式，保证键盘可达。

```css
.card {
  transition: transform .18s ease, box-shadow .18s ease, border-color .18s ease;
}
.card:hover {
  transform: translateY(-2px);
  border-color: rgba(36, 74, 56, .25);
  box-shadow: 0 8px 24px rgba(0, 0, 0, .06);
}
.card .arrow {
  color: #9aa39c;
  transition: transform .18s ease, color .18s ease;
}
.card:hover .arrow {
  color: #244a38;
  transform: translate(2px, -2px);
}
.card:focus-visible {
  outline: 2px solid #244a38;
  outline-offset: 3px;
}
```

> 手机端请配合第五章的 `@media (hover: hover)` 写法，避免触屏后 hover 状态残留。

### 6. 间距节奏（P1）

**现象**：搜索框 → 标签区 → "07 ITEMS" 之间空白约 60~80px，而卡片间距仅约 16px，头部显得松、内容显得紧。

**建议**

- 头部各区块间距收到 32~40px（手机端 16~24px）。
- 卡片间距放大到 20~24px（手机端 12px）。
- 使用统一的间距尺度（4 / 8 / 12 / 16 / 24 / 32 / 48）。

### 7. 小字号可读性（P2）

**现象**：`TAGS`、`07 ITEMS` 等小标签颜色偏浅；卡片内标签字号约 10~11px。

**建议**

- 辅助文字颜色加深，确保对比度不低于 **4.5:1**。
- 卡片内标签字号不小于 **12px**。
- 字母间距拉开的英文小标题可保留，但颜色加深一档。

### 8. 右下角粉色圆形元素（P2）

**现象**：截图右下边缘出现一个被裁切的粉色圆形。

**建议**：如果是悬浮按钮或装饰，请完整显示并留出安全边距（含 `env(safe-area-inset-*)`）；如果不是有意设计，检查是否为溢出元素。

### 9. 深色模式、可访问性与扩展性（P2）

- **深色模式**：目前 `theme-color` 只有浅色值，可补充深色版本。

  ```html
  <meta name="theme-color" content="#f6f7f3" media="(prefers-color-scheme: light)">
  <meta name="theme-color" content="#121512" media="(prefers-color-scheme: dark)">
  ```

  CSS 使用变量，在 `@media (prefers-color-scheme: dark)` 中重定义。

- **状态完整**：标签选中、hover、focus、disabled 状态都要有明确样式。
- **中文字体栈**：明确指定，避免平台差异。

  ```css
  font-family: -apple-system, "PingFang SC", "Noto Sans SC",
               "Microsoft YaHei", system-ui, sans-serif;
  ```

- **条目增长（30+ 项）**：
  - 增加分组标题或网格/列表切换。
  - `⌘K` 搜索支持匹配高亮、上下键选择、回车打开。
  - 筛选结果为空时给出友好的空状态。

## 四、平面设计规范

### 4.1 网格与对齐

- **使用统一栅格**：桌面端 12 列、移动端 4 列，列间距与卡片间距保持同一个值。当前 3 列卡片可明确为"每卡跨 4 列"。
- **所有元素对齐到同一条边线**：搜索框、`TAGS`、`ITEMS` 标题、卡片左缘保持在一条线上；卡片内部的图标、标题、简介、标签左边距一致。
- **间距使用倍数尺度**：4 / 8 / 12 / 16 / 24 / 32 / 48，避免随手写 13px、27px。

### 4.2 视觉层级

一个页面最好只有三层信息：

| 层级 | 作用 | 在本站中 |
|---|---|---|
| 一级 | 第一眼看到 | 软件名称、图标 |
| 二级 | 第二眼理解 | 一句话简介 |
| 三级 | 需要时才看 | 标签、箭头、条目数 |

用**字号、字重、灰度**三者共同拉开层级，不只靠颜色；相邻层级至少差一档，避免"差不多大又差不多灰"。

### 4.3 字体排印

| 项目 | 规范 |
|---|---|
| 字号比例 | 12 / 14 / 16 / 20 / 28（约 1.25 倍），一个页面不超过 4~5 种 |
| 字重 | 正文 400，标题 600，不再混入第三种 |
| 行高 | 中文正文 1.6~1.8；标题 1.3~1.4；小字标签 1.2~1.4 |
| 中英混排 | 中英文之间留细空格；英文专有名词（macOS、RSS、AI）保持原有大小写 |
| 字间距 | 全大写小标签（`TAGS`、`ITEMS`）加 0.06~0.1em；正文不调整 |
| 行长 | 中文每行约 25~40 字较舒适 |

### 4.4 色彩

- **60-30-10 法则**：约 60% 背景色（米白）、30% 辅助色（白卡片、灰字）、10% 强调色（深绿）。
- **第二强调色**：只用于"自己制作"等少量元素，面积远小于主色。
- **对比度**：正文不低于 4.5:1，大字不低于 3:1，可用 WebAIM Contrast Checker 检查。
- **灰色带色相**：保持偏暖偏绿的灰，与米白底协调，避免混入纯中性灰或偏蓝灰。
- **不单靠颜色传递信息**：配合文字或形状，照顾色弱用户。

### 4.5 留白

- 留白是设计元素：相关元素靠近，无关元素拉开（接近性原则）。
- 分组优先用间距，其次才用线框。
- 卡片内边距不小于 20px（手机端 16px），上下左右一致。

### 4.6 图标与图形

- 同一套功能图标保持同一种线宽、圆角与填充方式。
- 第三方软件图标无法统一，就用统一的容器（圆角、描边、底色）收敛差异。
- 图标尺寸固定，视觉重心居中；圆形略大于方形才显得一样大（光学对齐）。
- 功能性小图标（箭头、搜索）线宽约 1.5px，与文字字重协调。

### 4.7 一致性与组件规范

- 同类元素同一种样式：所有标签、所有卡片的圆角、内边距、字号、阴影一致。
- 建立状态表：默认 / hover / 按下 / 选中 / 聚焦 / 禁用，每种状态变化规则统一。
- 动效克制：时长 150~250ms，缓动用 `ease-out`；尊重 `prefers-reduced-motion`。

```css
@media (prefers-reduced-motion: reduce) {
  * { transition: none !important; animation: none !important; }
}
```

### 4.8 经典设计原则速查

| 原则 | 要点 | 检查方式 |
|---|---|---|
| 对比 | 重要的要明显不同 | 眯起眼睛看，重点是否仍然突出 |
| 重复 | 相同元素相同样式 | 抽三张卡片对比，样式是否完全一致 |
| 对齐 | 每个元素都有对齐对象 | 在设计稿上拉辅助线 |
| 亲密性 | 相关内容靠近成组 | 不看文字，仅看间距能否分出组 |
| 留白 | 给内容呼吸空间 | 局部是否拥挤，整体是否松散 |

### 4.9 落地方法

1. 先定设计令牌：颜色、字号、间距、圆角、阴影，写进 CSS 变量（见第七章）。
2. 做一张"样式表"页面：把所有组件各状态摆在一起，一眼检查一致性。
3. 用"眯眼测试"：缩小或模糊页面，看层级是否仍然清楚。
4. 每次只调一个变量，对比前后，避免连环失控。

**延伸阅读**：《写给大家看的设计书》（Robin Williams）、Material Design 与 Apple Human Interface Guidelines 的排版与间距章节、Refactoring UI。

## 五、响应式与手机端适配

### 5.1 断点与布局

| 屏幕宽度 | 卡片列数 | 页面左右边距 | 卡片间距 |
|---|:---:|:---:|:---:|
| ≥ 1024px（电脑） | 3 列 | 40px，内容最大宽度约 1200px | 20~24px |
| 640~1023px（平板/小窗口） | 2 列 | 24px | 16~20px |
| < 640px（手机竖屏） | 1 列 | 16px | 12px |

用 `auto-fill` 让列数自动变化，减少断点：

```css
.grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(min(100%, 320px), 1fr));
  gap: clamp(12px, 2vw, 24px);
}
.container {
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: clamp(16px, 4vw, 40px);
}
```

### 5.2 手机端卡片：横向紧凑布局（P0，对应 #11）

手机单列时，"图标在上、标题在下"的竖排卡片太高，一屏只能看到约 2 张。建议手机端改为图标在左、文字在右：

```
┌──────────────────────────────┐
│ [图标]  CleanupBuddy       ↗ │
│         清洁 Mac 键盘和触控板… │
│         推荐 macOS 系统工具     │
└──────────────────────────────┘
```

```css
@media (max-width: 639px) {
  .card {
    display: grid;
    grid-template-columns: 48px 1fr;
    column-gap: 14px;
    padding: 16px;
  }
  .card-icon { width: 48px; height: 48px; grid-row: 1 / span 3; }
  .card-desc {
    display: -webkit-box;
    -webkit-line-clamp: 2;
    -webkit-box-orient: vertical;
    overflow: hidden;
  }
}
```

这样一屏可看到 4~5 张卡片；简介限制 2 行，避免卡片高度参差。

### 5.3 搜索与标签区（P0，对应 #10）

**搜索框**

- 手机上隐藏 `⌘K` 提示（触屏没有该快捷键），只保留搜索图标。
- 输入框字号至少 **16px**，否则 iOS Safari 聚焦时会自动放大页面。

**标签区**

- 11 个标签平铺在手机上会折成多行，挤占首屏。改为**单行横向滚动**，右侧加渐隐提示可继续滑动。
- 分类与平台各占一行，各自横向滚动。
- 选中的标签自动滚动到可见区域。

```css
.tags {
  display: flex;
  gap: 8px;
  overflow-x: auto;
  scrollbar-width: none;
  -webkit-overflow-scrolling: touch;
  scroll-snap-type: x proximity;
  mask-image: linear-gradient(to right, #000 calc(100% - 24px), transparent);
}
.tags::-webkit-scrollbar { display: none; }
.tag { flex: none; scroll-snap-align: start; }
```

**压缩头部高度**：手机上可隐藏 `TAGS` 文字标签，搜索框与标签之间的空白收到 16~24px，让首屏尽快出现内容。

### 5.4 触控与交互（P1，对应 #12）

- **点击区域不小于 44×44px**：标签现高约 36px，手机端增加内边距至 40~44px。
- **hover 仅在支持 hover 的设备启用**，避免触屏点击后卡片一直停留在"上浮"状态：

  ```css
  @media (hover: hover) and (pointer: fine) {
    .card:hover { transform: translateY(-2px); }
  }
  .card:active { transform: scale(.99); }
  ```

- 整张卡片可点击，右上角箭头仅作视觉提示。
- 去掉点击高亮闪烁，并用自己的 `:active` 样式代替：

  ```css
  * { -webkit-tap-highlight-color: transparent; }
  ```

### 5.5 安全区与悬浮元素（P1，对应 #13）

页面已设置 `viewport-fit=cover`，内容会延伸到刘海与底部横条之下，必须处理安全区：

```css
body {
  padding-left: env(safe-area-inset-left);
  padding-right: env(safe-area-inset-right);
  padding-bottom: env(safe-area-inset-bottom);
}
.floating {
  position: fixed;
  right: 16px;
  bottom: calc(16px + env(safe-area-inset-bottom));
}
```

- 右下角悬浮元素在手机上可能与底部横条冲突，按上面方式定位。
- 可选：手机端搜索框做成粘性吸顶，长列表滚动时随时可搜索；注意与浏览器地址栏叠加造成的遮挡。

### 5.6 响应式排版

用 `clamp()` 让字号平滑过渡，不在断点处突变：

```css
h1          { font-size: clamp(24px, 4vw, 32px); }
.card-title { font-size: clamp(16px, 1.6vw, 18px); }
.card-desc  { font-size: 14px; }   /* 手机不低于 14px */
```

- 卡片内标签手机上不低于 12px，对比度保持 4.5:1。
- 英文软件名较长（如 System Data Unpacked）时使用 `overflow-wrap: anywhere` 或 `text-wrap: balance`，避免撑破布局。

### 5.7 其他细节

- **图片加载**：图标加 `loading="lazy"` 和明确的 `width/height`，防止布局抖动；优先使用 WebP/SVG。
- **暗色模式**：手机用户夜间使用比例高，建议优先做，并为 `theme-color` 分别设置浅色/深色。
- **手机横屏**：宽度 600~900px、高度很小，用 `@media (max-height: 480px)` 压缩头部间距。
- **大字体设置**：系统开启大字体后，确认布局不被撑坏。

## 七、设计令牌参考

```css
:root {
  /* 颜色 */
  --bg: #f6f7f3;
```
